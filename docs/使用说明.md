# 使用说明（面向受训者 / 助教）

> 项目代号：MOCK-INTERVIEW-AGENT · 交付编号 D3 · 版本 V4.0 · 2026-09

## 面向受训者

1. **登录**：打开系统首页，使用演示账号 `demo@test.com / secret123` 登录，或点击「注册」创建账号。
2. **配置面试**（可全部默认，直接点「进入面试房间」）：
   - 岗位类型：默认「数据分析」，可切换后端 / 前端 / 算法 / 产品
   - 目标公司（可选）：选择则结合公司业务出题
   - 技术要求（可选）：勾选预设或手动输入自定义技术项
   - 题量：不限（随时可结束）或固定题数
   - 岗位 JD（可选）：粘贴实习 JD，将按 JD 定制出题与匹配评估
   - 简历（可选）：上传 PDF / Word（≤10MB），内容将进入本场面试上下文
3. **设备调试（面试前可选）**：进入面试房间后先显示调试面板——①扬声器播放测试音、②麦克风波形与音量条、③语音识别回显、④摄像头预览（可跳过）。全部通过会提示"调试通过"，**未通过也可直接点「进入面试」**；此阶段不出题、不消耗每日次数。
4. **进入面试（仅语音作答）**：
   - 面试官先**开口播报开场白**并引导自我介绍 → 第 1 题固定为「自我介绍（1 分钟左右）」 → 第 2 题起进入正式技术提问。
   - 每题流程：点「开始作答」开麦说话（实时转写）→ 点「结束作答」提交，或停顿约 3.5 秒自动提交 → 面试官点评与追问 → 继续下一题。
   - 想打断面试官：点「插话」；点「结束面试」结束本场。
5. **结束面试**：对麦克风说「结束对话 / 回答完毕 / 今天就到这」等关键词，或点「结束面试」；过程分累计达 80 分也会提前结束。不限题量时随时可结束，统一评分。
6. **查看报告**：自动跳转报告页（单屏布局）——综合得分、五维评分（每维引用第 N 题作答）、逐题点评与示范答案（点击展开）、知识总结、口头禅统计、简历诊断评分与优化建议（可编辑并保存）；右上角「导出报告」可下载 Markdown 全文。

## 次数规则

- 每日训练配额默认 **5 场**，跨日自动恢复；配置页可查看「今日剩余次数」
- 配额用尽后无法新建面试，系统会明确提示

## 面向助教（演示）

按 `README.md` 的「启动」步骤两步即可拉起前后端；用演示账号走完：
配置 → 调试（可跳过）→ 开场白（语音）→ 自我介绍第 1 题 → 点「开始作答/结束作答」答一题并观看点评 → 点「结束面试」→ 查看报告并导出。
面试仅支持语音作答，请确保浏览器（Chrome / Edge）已授权麦克风。

## 常见问题

- **麦克风无法打开**：调试页点「重新获取并测试」，并在浏览器地址栏允许权限；仍未解决可直接进入，但答题将无法转写。
- **没有语音 / 听不到面试官**：浏览器无 TTS 时面试官以文字展示并继续流程；检查系统音量与「面试官音量」滑杆。
- **调试某项不过**：不影响进入，面试功能会部分受限；摄像头可跳过。
- **想再看一遍自己的回答**：报告「完整对话记录」含逐字稿；也可导出报告保存。
- **评分会不会乱给**：不会。未作答一律 0 分；每维评分都引用具体题目与作答；综合分按逐题质量加权，后端校验修正。
- **系统把我的面试当真实招聘吗**：不，系统仅用于教学训练，报告页脚与导出文件均有免责声明。
