# 使用说明（面向受训者 / 助教）

## 面向受训者

1. **登录**：打开系统首页，使用演示账号 `demo@test.com / secret123` 登录，或点击「注册」创建账号。
2. **配置面试**（可全部默认，直接点「进入面试房间」）：
   - 岗位类型：默认「数据分析」，可切换后端 / 前端 / 算法 / 产品
   - 目标公司（可选）：选择则结合公司业务出题
   - 技术要求（可选）：勾选预设或手动输入自定义技术项
   - 题量：不限（随时可结束）或固定题数
   - 岗位 JD（可选）：粘贴实习 JD，将按 JD 定制出题与匹配评估
   - 简历（可选）：上传 PDF / Word（≤10MB），内容将进入本场面试上下文
3. **进入面试房间**：
   - 授权浏览器麦克风（摄像头可选）；若拒绝或浏览器不支持语音，系统自动切换为**文字输入模式**，照常进行
   - 面试官先致开场白并引导自我介绍，然后逐题问答；每题回答后收到点评与追问
   - 想打断面试官：点「插话」
4. **结束面试**：对麦克风说「结束对话」，或点「结束面试」（不限题量时随时可结束，随后统一评分）
5. **查看报告**：自动跳转报告页——综合得分、五维评分、逐题点评与示范答案（点击展开）、知识总结、口头禅统计、简历优化建议（可编辑并保存）

## 次数规则

- 每日训练配额默认 **5 场**，跨日自动恢复；配置页可查看「今日剩余次数」
- 配额用尽后无法新建面试，系统会明确提示

## 面向助教（演示）

按 `README.md` 的「启动」步骤两步即可拉起前后端；用演示账号走完：
配置 → 入房 → 开场白 → 答一题并观看点评 → 点「结束面试」→ 查看报告。
无麦克风环境请直接点击「改用文字输入」演示文字模式（评分结果一致）。

## 常见问题

- **麦克风无法打开**：检查浏览器地址栏授予权限；仍失败则自动进入文字模式，不影响评分。
- **没有语音**：浏览器不支持 TTS 时，面试官以文字展示提问，可正常作答。
- **想再看一遍自己的回答**：报告「完整对话记录」含逐字稿。
- **系统把我的面试当真实招聘吗**：不，系统仅用于教学训练，报告右上角与页脚均有免责声明。
