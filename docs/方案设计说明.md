# 方案设计说明（任务书附件 Q1–Q8）

本文件记录关键设计决策与理由，作为开题、中期与答辩底稿。现场说明与本文件保持一致。

## Q1 训练定位与考察重心

- **默认岗位**：数据分析及相关业务岗位（任务书 2.3）。考察重心：SQL 与取数、统计与概率基础、指标体系搭建、AB 实验方法、数据可视化与业务洞察表达（`packages/data` 中 `roleLine.data` 对应人设提示词）。
- **扩展岗位**：后端开发、前端开发、算法、产品经理（同一套引擎，仅人设与重点不同）。
- **取舍依据**：任务书明确默认数据分析；保留其余岗位用于演示覆盖面对比，答辩时说明扩岗仅改人设、不改变主流程。

## Q2 场次定义与结束条件

- **开始**：创建面试即生成第 1 题（`services/interview.ts#nextQuestion`）。
- **开场**：WS 会话首帧发送开场白（问候 + 教学训练声明 + 自我介绍引导），构成“开场”阶段（`rt/interview-ws.ts`）。
- **推进**：每轮 一题一答 → AI 点评（亮点 / 不足 / 1 个追问）→ 进入下一题；追问上限 1 轮，防止会话失控。
- **结束**：三种途径——① 关键词（“结束对话 / 回答完毕 / 今天就到这 / 结束面试”）；② 手动点击「结束面试」；③ 限题模式答完既定题数。
- **收束**：`handleEnding` 统一收尾：补齐题目 → 状态置 complete → 五维评分 + 知识总结 + 逐题示范答案，前端跳报告。

## Q3 材料进入方式与缺失处理

- **进入方式**：简历文本、JD、目标公司业务/技术栈、所选技术要求合并注入人设 system prompt（`packages/data#getPersona`）。
- **缺失处理**：简历未上传时摘要明示“未上传”，按通用岗位标准问答，评分不受阻断；JD 未填时按岗位 + 技术清单出题。

## Q4 追问、换题与收束原则

- 作答后 AI 先肯定正确部分、指出不足，再给 1 个针对性追问；追问后本题结束换下一题（难度递增、不重复）。
- 追问次数固定 1 轮（`interview-ws.ts` followupCount 上限），避免无目标闲聊；AI 回答包含结束意图（“未答完/今天就这样”）时可触发收尾。
- 检测到结束关键词即刻进入 `handleEnding`。

## Q5 语音主路径与备用路径

- **主路径**：前端 Web Speech API（webkitSpeechRecognition 中文识别 + speechSynthesis 本地 TTS）；后端配置 TTS Key 时改用服务端合成音频回传。
- **备用路径**：媒体权限被拒、识别不可用或浏览器不支持时，自动切换到**文字对话模式**（WS 新增 `answer` 文本消息），问答与评分流程完全一致，训练不中断。
- **可演示环境承诺**：最新版 Chrome / Edge（Windows）可完整演示语音主路径；任意现代浏览器可演示文字模式全流程。

## Q6 评价反馈策略

- **解决什么问题**：让受训者知道“答得如何、差在哪、怎么补”。
- **维度组织（可解释）**：技术准确性、逻辑表达、沟通流畅度、应变能力、综合评分（各维度附一句话 comment）；每题含作答实录、面试官点评、参考示范；另有知识总结、口头禅统计、简历优化报告。
- 报告页所有维度含义可上溯到对应题目与逐字稿，避免不可解释的单一结论。

## Q7 次数管理与公平安排

- `users` 表新增 `quota_limit`（默认 5）、`quota_date`、`quota_used`；按自然日重置，创建面试时原子消费（`routes/interviews.ts` POST）。
- 配置页展示「今日剩余次数」，用尽后创建返回 403 并提示“明日起自动恢复”。
- 公平性：同一配额口径对全体用户一致；无内购强制项；答辩时可现场演示配额耗尽与恢复。

## Q8 主要风险与应对

| 风险 | 应对 |
| --- | --- |
| 中国大陆语音 API 不可用 | 文字对话模式兜底；TTS 用浏览器本地 synthesis |
| LLM 超时 / 失败 | `llm.ts#chat` 失败降级 mock 回复，不返回 500 |
| 识别乱码 / 空结果 | VAD 1.2s 静音判停；空文本不提交；可改用文字模式 |
| 媒体权限被拒 | 自动降级文字模式并给出明确提示 |
| 数据泄露 / 清理 | 密钥在 .env 不入库；数据存本地 PGlite，删除目录即清 |
| 会话失控（无限追问） | 单题追问上限 1 轮、一题一答、半双工轮转 |
